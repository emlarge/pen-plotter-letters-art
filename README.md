# Pen Plotter Letters — cover art

Public asset repo. Contains only cover artwork, no story text — the story
content lives in a separate private repository.

Images are referenced by other services via their raw GitHub URL:
`https://raw.githubusercontent.com/emlarge/pen-plotter-letters-art/main/<path>`

## Layout

```
covers/<story-folder-slug>.png   one cover per story, reused across all
                                  of that story's episodes
```

Style: linocut woodblock print, black and warm ochre, folk-art relief
printing — consistent across every story's cover.
